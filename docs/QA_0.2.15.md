# Android 0.2.15 底部系统栏修复

复现条件：Android 使用深色系统主题，邮箱手动选择浅色。0.2.14 的原生窗口仍使用系统 DayNight 背景，导致浅色页面底部出现一块深色导航区域，顶部也存在相同色差。

修复：增加仅接收主题布尔值的 AppAppearance 原生桥，同步系统栏背景和图标明暗；系统配置变化后再次应用当前 App 主题。保留系统手势横线、三键导航和现有安全区尺寸，不隐藏系统导航。修复邮箱“跟随系统”模式仅更新内部状态而未应用主题的问题。Android 7 不支持深色导航图标，保留该系统的黑色导航栏以确保可读性。

验证：已登录模拟器覆盖安装 0.2.15，系统深色 + App 浅色下，手势导航及三键导航均为浅色背景，图标清晰；切换 App 深色及导航模式后复查。TypeScript、联网 APK 构建、9 项 Android 单元测试、关键 release lint 和签名验证通过。正式包关闭 WebView 调试。未对其他手机厂商系统做真机验收。
