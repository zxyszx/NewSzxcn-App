# NewSzxcn Android 0.2.8

- 邮箱管理新增同级「外部邮箱」，位于「我的邮箱」右侧。
- 外部账号统一列表增加接收邮箱选择、搜索、状态、最近同步和失败重试。
- 保存失败保留输入；直连账号不再显示可用的本地同步操作。
- 新建密码账号仅提供加密连接；标准端口随 SSL/TLS、STARTTLS 切换，自定义端口保留。

版本号 0.2.8，versionCode 12，包名 com.newszxcn.newmail，沿用正式版签名。
可覆盖安装此前官方签名版本，无需卸载或清除数据。

连接 https://mail.newszxcn.com。服务端需更新至配套版本，外部邮箱接入还需
管理员启用及单独账号授权。Gmail、Outlook 的 OAuth 配置和真实接入验收尚未完成；
此版本不包含外部 SMTP 发信或自动转发，不应理解为所有外部邮箱已经可用。
沿用现有 FCM 通知，国内推送尚未接通。

隔离 Android 模拟器已完成外部邮箱专项测试，以及 30 个设置/后台子页面、
8 个编辑流程的回归。真实外部邮箱收发信和端到端通知未在本版本重新验收。

配套服务端 v1.2.93 包含 Maildir 重复解析和无变化写库的优化。
服务器 CPU 改善幅度需部署后重新测量，安装 APK 本身不会降低服务端 CPU。
