# Android 0.2.14 检查记录

## 范围与结果

按用户要求恢复 0.2.12 的网页式邮箱界面，撤回 0.2.13 新增的手机底部导航、顶部邮箱切换栏和头像式勾选框。检查更新仍在设置 → 关于。原有登录、系统通知和邮件链接外部打开逻辑保留。

| 问题 | 原因及处理 |
| --- | --- |
| 手机邮件时间、星标看不到，长主题溢出 | 滚动组件内部的 table 容器按长内容撑宽。手机邮件列表改用宽度受限的块容器，标题截断并保留时间、星标。 |
| 手机进入页面时短暂显示桌面布局 | 移动端断点初始值延迟到 effect；改为首帧读取 matchMedia。 |
| 未读筛选可能漏掉未加载页中的邮件 | 未读、星标、附件快捷条件接入已有服务端搜索参数，原活动条件标签保留。 |
| 切换筛选后仍残留此前选择 | 筛选、附加约束、重点收件箱切换时清除勾选。 |
| 手机顶栏功能拥挤 | 导入、导出放入“更多邮件操作”，保留权限和可用状态限制。 |
| APK 外观设置出现空背景区 | 公开包没有可分发背景时隐藏空分组；修复范围滑块误用输入框边框。 |
| 文件共享范围过大 | FileProvider 从整个外部存储、缓存收窄为拍照 Pictures 与 capacitorassets 临时附件目录。 |
| 依赖安全告警 | DOMPurify 升至 3.4.17，Tiptap 升至 3.33.1，ProseMirror 依赖去重并使用修补版本。发布检查时 pnpm audit --prod 为 0 条已知告警。 |

## 验证

- Web TypeScript / 构建 / shadcn 检查通过。
- 320、390、767、1024、1440px：活动筛选显示、清除筛选、工具栏边界检查通过。手机尺寸另检查侧栏展开/关闭、设置分组展开/返回、浅色/深色切换。
- 已登录 Android 模拟器：未读筛选保持手机布局；侧栏打开正常；账号、邮件、通知与客户端、安全、外观、关于、邮箱管理、联系人管理、邮件清理、待清理邮件、收信规则、被拦截邮件、数据统计、开发者页面可展开并逐级返回；写信、抄送、密送展开与取消正常。未发送新的真实邮件。
- 模拟器确认长标题截断，时间、星标在屏幕内。调试构建只用于定位问题；正式包关闭 WebView 调试。
- Android 9 项单元测试通过，release 构建与 lintVitalRelease 通过；长期发布签名验证通过。

## 限制

这次是客户端回退与针对性缺陷检查，不是完整渗透测试。没有在本轮重做后台推送、锁屏、厂商省电、外部邮箱真实授权及真实附件上传/下载的全套验收；国内推送仍未接通。外部邮箱与未知邮件视图的快捷筛选仍受各自查询实现限制。没有修改或部署邮箱服务器，服务器版本须支持现有搜索参数。依赖扫描无告警不代表不存在未知漏洞。
