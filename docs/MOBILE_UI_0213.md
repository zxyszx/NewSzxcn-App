# 0.2.13 手机界面验收

## 本轮变化

- 邮箱、账号、设置三个根页面共用底栏。外观支持固定／悬浮，选择本地持久保存。
- 进入设置子页或阅读邮件时隐藏底栏，逐级返回；保留原有系统返回处理。
- 设置 → 关于包含 APK 版本、检查更新与 GitHub 发布页，不调用管理员的服务器更新 API。
- 收件箱顶栏复用已有邮箱选择器和查询权限，保留导入／导出、写邮件。手机邮件行使用头像式选择控件、时间下方星标；桌面布局保持原有网格。
- 页面短距离滑入／淡入，遵从减少动态效果偏好。

## 已验证

- TypeScript、生产打包及 shadcn 检查通过。
- Android release 单元测试、打包、lintVitalRelease 通过。
- 浏览器 390px：主导航点击、关于入口、模拟 GitHub 响应的更新检查、外观持久化、账号页、阅读页隐藏底栏并返回恢复、无水平溢出；1440px 不显示手机底栏。
- 正式签名 APK 覆盖安装并在 NewSzxcn_Compare 模拟器启动至真实登录页。

## 尚未完成的验收

模拟器当前未登录，本轮未重新验证原生登录后的收发信、通知与全部管理子页。浏览器使用演示数据，不能替代这些真实服务验收。安装后应检查系统返回、键盘弹出、锁屏通知及大字体。此版本更新检查只引导到发布页下载安装，不会静默安装。
