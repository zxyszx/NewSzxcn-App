# 联网联调与验收

## 构建模式

- `android:sync:public`：离线只读演示，不连接真实邮箱。
- `android:sync:live`：连接 `https://mail.newszxcn.com`，使用真实账号。
- 两种构建均保留 APK 内的界面资源，不使用 `server.url` 下载远程应用界面。
- 联网模式仅将指定 HTTPS 主机的 `/api/*` 和 `/healthz` 请求交给 WebView 网络栈；会话使用服务器 Cookie，不放宽 CORS 或第三方 Cookie。
- 默认禁用联网版 WebView 调试。`NEWSZXCN_WEBVIEW_DEBUG=true` 仅供本机联调，不应用于公开安装包。

构建后执行 `./gradlew :app:testDebugUnitTest :app:assembleDebug`。附件采用系统文件保存器，下载限制 100 MB，不跟随重定向；下载失败不会把 Cookie 转发给其他主机。
